# Contributing

First of all, thank you for considering contributing to this project! ❤️

Every contribution, whether it's fixing a bug, improving the documentation, or adding a new feature, is greatly appreciated.

---

# Before You Start

Please make sure you have:

- Read the project documentation.
- Tested your changes before submitting them.
- Followed the project's coding style.
- Written clear and maintainable code.

---

# Reporting Bugs

If you discover a bug, please include:

- A clear description of the issue.
- Steps to reproduce it.
- The expected behavior.
- The actual behavior.
- Screenshots or logs (if applicable).

---

# Suggesting Features

Feature requests are always welcome.

Before starting to implement a large feature, please contact me first so we can discuss whether it fits the project's roadmap.

---

# Pull Requests

Before opening a Pull Request, please make sure that:

- Your branch is up to date with the latest version.
- Your code has been tested.
- There are no unnecessary files or formatting changes.
- The Pull Request clearly explains what has changed and why.

# Code Style

Please follow these general guidelines:

- Write clean and readable code.
- Use meaningful variable and function names.
- Keep functions focused on a single responsibility.
- Avoid unnecessary dependencies.
- Comment only when something is not immediately obvious.

---

# Documentation

If your contribution changes the project's behavior, please update the corresponding documentation whenever possible.

Good documentation is just as valuable as good code.

---

# Respect

Please be respectful when interacting with other contributors.

Constructive feedback is always welcome.
